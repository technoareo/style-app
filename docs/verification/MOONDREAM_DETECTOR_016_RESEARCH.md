# Free local wardrobe detection follow-up (2026-10-22)

The remaining consumer gap is reliable separation of multiple garments in a crowded wardrobe photo. This is research only; no user images were sent, no model was downloaded, and no code was changed.

- The original Moondream 2 checkpoint and Xenova's ONNX conversion both list Apache-2.0. The third-party `gatorchopps/moondream2-region-onnx` lists Apache-2.0 and supplies four region ONNX components (~230 MB) for object detection/pointing, but these are only an add-on to the vision encoder and text decoder. Sources: https://huggingface.co/vikhyatk/moondream2 , https://huggingface.co/Xenova/moondream2 , https://huggingface.co/gatorchopps/moondream2-region-onnx .
- The model card explicitly says detection is autoregressive and its supplied JS module needs a `textModelStep` callback with hidden-state access. Transformers.js does not expose the required hidden states natively; integration requires loading the decoder ONNX directly or patching the library. There is no verified drop-in working end-to-end JS detector here. Source: https://huggingface.co/gatorchopps/moondream2-region-onnx .
- The official current Moondream local engine requires NVIDIA Ampere or newer or Apple Silicon; this Windows host has an AMD Radeon 5300M. The official Transformers path can run on other hardware, but its CPU speed/accuracy on this wardrobe task is unmeasured. Sources: https://docs.moondream.ai/running-locally/ and https://docs.moondream.ai/transformers/ .
- YOLO-World's official repository claims GPL-v3 and offers ONNX export, while its `pyproject.toml` says Apache-2.0. This conflicting license metadata requires clarification before embedding it in the launch stack. Sources: https://github.com/AILab-CVC/YOLO-World and https://github.com/AILab-CVC/YOLO-World/blob/master/pyproject.toml .

Decision: keep the existing capped, user-reviewed photo flow while researching and measuring a genuinely working local detector. The Moondream ONNX add-on is a possible prototype, not evidence that whole-wardrobe automatic extraction works or will meet this machine's latency budget. A representative, consented and labelled wardrobe photo set plus measured recall, false discoveries and time-to-first-result are still required before launch acceptance.
