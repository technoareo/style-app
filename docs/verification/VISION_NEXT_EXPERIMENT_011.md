## Results and preprocessing check

The three-tile fp32 probe completed offline: 27.26, 41.19 and 40.96 seconds per tile; 114.95 seconds total. It returned zero, one and one proposals. The two surviving labels were `shorts` and `shirt`, scores 0.320 and 0.276. Root inspected the public original: the shorts box covers a small lower section of hanging material without an identifiable complete pair of shorts; the shirt region spans overlapping right-side clothing. This is qualitative development-fixture inspection, not an independent gold annotation. It does not demonstrate useful item isolation or wardrobe coverage. Sampled RSS was about 3.18 GB, not a whole-run measured peak.

The [original model's processor configuration](https://huggingface.co/IDEA-Research/grounding-dino-tiny/blob/main/preprocessor_config.json) uses shortest edge 800 and longest edge 1333. The pinned converted configuration instead resizes to width 800 and height 800. `detector-shape-probe-011.json` confirms the actual fp32 ONNX graph has static `[1,3,800,800]` image and `[1,800,800]` mask inputs. Direct rectangular inference is therefore not assumed compatible.

Root tested an isolated alternative without changing weights or thresholds: preserve the full normalized 1600×1200 fixture at 800×600, pad the bottom to 800×800, explicitly set 160000 padding mask values to zero and normalized padding pixels to zero, then use the pinned graph. `detector-letterbox-fp32-011.json` records valid mask verification, 50.03 seconds inference, 57.76 seconds total and **zero proposals**. Preserving proportions this way did not solve the fixture. This differs from a native rectangular graph and does not prove that every preprocessing alternative is ineffective. No application integration or production accuracy claim follows.

## Full SDK loader through offline WASM

`vision-sdk-wasm-probe-011.mjs` tested the installed Transformers.js custom-runtime hook (`Symbol.for('onnxruntime')`, found in its backend source), `device: auto` with explicit WASM providers, and a guarded adapter converting known public-cache model paths to bytes. Installed package files were not patched. Remote model loading and WASM caching were disabled; runtime assets remained local. The full `AutoModelForZeroShotObjectDetection` loader and forward call succeeded: one session created, 5.86 seconds load, 51.77 seconds inference, one shirt-control proposal at score 0.768, 58.29 seconds total. Evidence: `vision-sdk-wasm-probe-011.json`. This is a research-only runtime adapter, not a supported production compatibility promise or recognition benchmark. It enables testing another model family's normal generation code without implementing a custom decoding loop or changing the application's dependencies.
